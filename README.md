# Simple To-Do App 📝

A lightweight and easy-to-use **To-Do List web application** built with **HTML, CSS, and JavaScript**.  
Keep track of your tasks quickly and easily, with tasks saved in your browser using **Local Storage**.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks individually
- Persistent tasks using browser local storage
- Clean and simple user interface

---

## 🛠️ Technologies Used

-HTML5
-CSS3
-JavaScript (Vanilla JS)
-Local Storage API
